# Expirix — 5-minute demo script

1. **Open** https://expirix.vercel.app. The logo intro plays (Skip works). Point out the English/हिन्दी switch.
2. **Try the demo shop** (no sign-up). Dashboard: totals, items expiring soon, value at risk.
3. **Inventory** → search, filter by status. Open a product: batches, movement history.
4. **Add a product.** Tap *Scan barcode*: live camera, or photograph the barcode. Unknown code opens the form pre-filled.
5. **Record stock out** (sold / damaged / expired) and show the history updating.
6. **Alerts** → expired and expiring lists. Tap *Share on WhatsApp* to send the summary.
7. **Reports and Calendar** → waste cost, expiry by date.
8. **Settings** → thresholds, language, backup download.
9. **Create a real account** (cloud): confirmation email, *Forgot password?* flow. Show the first-run checklist and *Fill with sample products*.
10. **Settings → Alert delivery**: email digest toggle, *Send me a test email*, enable push, install to home screen.
11. **Close**: data is isolated per shop (RLS), can be exported, and the account can be deleted.

Fallback if the network fails: demo mode works fully offline in the browser.
